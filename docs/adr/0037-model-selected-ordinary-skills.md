# ADR-0037：由当前角色模型按需选择普通技能

状态：已采纳；维护者已批准 #336 单票完整方案。最后核验：2026-11-09。
事实来源：[批准规格](../specs/skill-discovery-and-reuse-proposal.md)、[宿主技能库](../../backend/app/skill_library.py)、[受控读取](../../backend/app/agent_runtime/skill_discovery.py)、[公开行为测试](../../tests/python/test_skill_discovery.py)、[窗口与来源测试](../../tests/python/test_skill_lifecycle.py)。

## 背景与决定

关键词匹配不能稳定识别改写后的任务，常驻正文又会占用无关上下文。普通对话保留现有角色模型和工具循环：宿主提供有界目录，模型在需要时通过常驻 `skill_list` / `skill_read` 读取方法。没有固定的分类或事后创作请求，也不新增执行器、向量检索或工具注册框架。

目录与读取共用当前角色的文件发现、同 ID 覆盖、hash 和依赖校验。模型只接收不含宿主路径的来源引用；资源只接受该技能已发现索引中的条目。文件、Shell、MCP、渠道和凭据仍遵循现有注册表及真实来源权限。未触发工具的上下文和访客没有新增 schema，脚本读取不执行。延续 ADR-0032 的当前工具注册表，不恢复普通工具执行器固定或完整目录版本链。

开始运行时固定可见技能、来源和调用策略。后续检查同时接受最初范围与当前权限的约束；中途放开手动限制不能扩大旧运行，停用或撤权可以立即缩小后续读取和恢复。运行内变化只返回诊断，下一轮发现新版本。明确指定只取当前主人直接输入与 `skillIds`，引用文本、代码样例、附件和旧历史不产生本轮手动授权。

手动授权解析排除行内、缩进及不同长度围栏的 Markdown 代码。桌面及渠道在显示文本规范化前捕获直接输入；渠道保留的临时授权文本不含引用扩充、附件文件名或宿主失败提示，也不写入原消息历史。

引用使用逻辑来源、相对 bundle 身份及角色/新旧目录区分，不包含绝对 codeRoot；因此应用换 release 后，主人的停用与手动选择不会丢失。hash 与引用分开校验。文本资源随实际指导恢复；图片被窗口移出后提示重新读取，不能仅凭文字记录声称仍能检查图片。

首次正文交付和按需读取分别形成真实记录，包含来源引用、角色、会话、运行和内容 hash。只有实际成功读取的正文与资源保留在运行内存；当前有效窗口已含完整回执时不再注入。窗口移除原回执后，从仍有效的本轮读取恢复指导并计入同一请求预算。沿用 ADR-0036 的合法窗口与 minimal 降级，恢复不重放模型或业务工具，不跨线程或角色取正文。进程重启没有自动续跑，延续 ADR-0035。

## 格式、迁移和持久位置

简单格式接受 `name`、`description` 和正文，保留既有 ID、版本、工具与依赖字段。支持布尔 `allow_implicit_invocation` 及 `policy` 下的同名字段；冲突设置拒绝。YAML 使用安全解析，重复键、别名和越界/链接资源拒绝；外部宿主专用元数据列出但不执行。

已有角色默认继续旧触发方式。主人先看迁移预览，再逐角色启用：旧显式技能保持手动；关键词变为模型选择；常驻指导保留；内置方法逐项采用已审阅的自动策略。单项设置可覆盖自动/手动/常驻，回退关闭目录和读取、恢复原触发方式，不批量改写旧文件或删除文件。

角色私有、角色旧目录、主人公共库、项目与内置依次覆盖。停用私有覆盖后，低优先级版本可以恢复。**部署适配**：公共发布写应用数据目录 `shared-skills/`，不写版本化 release、项目 `.agents/` 或内置目录；因此日常更新不丢失主人发布的方法。发布是主人管理页的独立明确操作，聊天模型没有公共发布工具。

聊天文件工具与管理页共用格式校验，保存之后实际读回核验；同 ID 更新要持有当前 hash，资源默认保留。缺资源可以保存为不完整项，但不能报告完整可用。普通上传没有安装副作用。首版支持 Markdown 和明确提供的有界资源，不提供市场安装或远程依赖拉取。

聊天更新已有正文或资源时，宿主按角色、会话、运行和文件身份保留 `read_file` 从实际读取字节得到的版本；历史回执不授予本轮写入版本。管理保存与聊天文件提交使用同一短事务锁，最终版本比较与原子替换处于同一事务，冲突要求重新读取和协调。普通非技能文件保持原合同。模型按需实际读取内置长期技能创作方法后，可以沿原作者证据合同记录作者；记录仍逐次核对当前技能来源、hash、独立作者许可及来源范围，私有同 ID 或仅见过目录不能取得该证据。

## 取舍与评估

第一次选择通常增加一个已有工具循环往返，换来更小的初始指导。目录预算为已知容量的 2%，未知容量上限 8,000 字符；超出明确标记并分页。完整正文和资源有独立有界读取上限，并继续受真实整体请求预算约束，不能截半份正文当作完整加载。

可控适配器、真实 HTTP 和文件往返证明程序合同，不能证明任意真实模型的语义选择质量。固定 12 正例、12 负例、6 相邻请求、每项 3 次的离线证据模板与评分器独立提供；它们不连接真实模型、不自动消费付费额度。只有采集实际读取和成果证据后，才能按模型报告效果及额外开销。

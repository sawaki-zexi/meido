# ADR-0033：已有 Herdr session 的代理接手

状态：已采纳；2026-10-30 维护者批准 #279/#284 的现有 session 四工具、进程内追踪与原聊天回报。
事实来源：[Ticket #284](https://github.com/sawaki-zexi/meido/issues/284)、
[接口与验证](../reference/herdr-session-agents.md)、固定 Shiori `71c8b0e`。

ADR-0017 的受管编程任务拥有独立 server、worktree 与成果账本，不能发现主人手动打开的代理。
本决定新增已有 session 控制，与受管任务并存，不替换其资源所有权和授权。

四工具共享一个输入路径与进程内记录。CLI 子进程由本次调用负责回收；
目标 session、server 与代理不归 Meido 所有，关闭插件只停止观察。
接手、追踪和命令回报不持久恢复，从而不会在重启后重放输入或继续接管用户代理。
代价是重启后需要角色在新的真实用户回合重新接手，原终端状态仍由 Herdr 持有。

回报目标来自实际来源的宿主捕获，进入原角色普通工具回合；
内部事件保留独立类型，不冒充新主人输入。当前接手者可回应回报，其他角色不能借此取得输入权限。
投递与指令的不确定状态保留原事实，最多尝试一次，以避免重复执行不可撤销输入。
设置使用已有全局配置入口，工具沿 ADR-0032；不引入通用插件 ABI 或第二套任务账本。

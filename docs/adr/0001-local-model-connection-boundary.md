# ADR-0001：本地模型连接边界

## 状态

已接受（协议接入范围由 [ADR-0006](0006-provider-specific-model-adapters.md) 扩展）

## 决定

当前通过本地后端管理模型连接。网页只编辑草稿、发起测试和展示结果；后端是已保存配置和实际模型调用的权威来源。角色绑定模型连接的稳定身份，不直接保存服务商密钥。

连接测试使用当前未保存草稿，并验证实际对话所需的流式请求路径。测试成功不会自动保存配置，只有用户明确保存后才进入可用模型目录。

## 原因

- API Key 不应由网页直接管理或写入普通日志。
- 草稿测试不应意外改变正在使用的配置。
- 后端统一模型调用边界，便于后续增加服务商而不让角色和会话逻辑依赖具体 SDK。
- 角色只保存稳定连接身份，可以独立切换模型而不改变角色、会话和历史消息。

## 范围

本 ADR 原先限定为 Shiori 参考范围内的服务商预设和 OpenAI Chat Completions 兼容的
自定义服务商。后续协议范围由 ADR-0006 扩展；本 ADR 关于本地后端持有配置、网页
维护草稿以及角色只绑定稳定连接 ID 的边界继续有效。

## 后果

模型配置、测试和实际调用必须经过本地后端；前端需要区分未保存草稿和已保存配置。后续增加服务商时需要接入统一的模型适配边界。

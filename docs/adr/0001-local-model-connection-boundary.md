# ADR-0001：本地模型连接边界

## 状态

已接受

## 决定

第一版通过本地后端管理模型连接。网页只编辑草稿、发起测试和展示结果；后端是已保存配置和实际模型调用的权威来源。角色绑定模型连接的稳定身份，不直接保存服务商密钥。

连接测试使用当前未保存草稿，并验证实际对话所需的流式请求路径。测试成功不会自动保存配置，只有用户明确保存后才进入可用模型目录。

## 原因

- API Key 不应由网页直接管理或写入普通日志。
- 草稿测试不应意外改变正在使用的配置。
- 后端统一模型调用边界，便于后续增加服务商而不让角色和会话逻辑依赖具体 SDK。
- 角色只保存稳定连接身份，可以独立切换模型而不改变角色、会话和历史消息。

## 范围

第一版支持 Shiori 参考范围内的服务商预设，以及 OpenAI Chat Completions 兼容的自定义服务商。具体存储引擎、传输协议和密钥加密方式由实现计划确认，不在本 ADR 中预先指定。

## 后果

模型配置、测试和实际调用必须经过本地后端；前端需要区分未保存草稿和已保存配置。后续增加服务商时需要接入统一的模型适配边界。

# ADR-0039 主人近期群发言使用有界只读投影

状态为已采纳，依据维护者确认的 Spec #360 与开发任务 #363。最后核验日期为 2026-11-12。

事实来源为 [Spec #360](https://github.com/sawaki-zexi/meido/issues/360)、[开发任务 #363](https://github.com/sawaki-zexi/meido/issues/363)、[投影实现](../../backend/app/owner_group_speech.py)和[入口验收](../../tests/python/test_owner_group_speech_api.py)。

## 背景

ADR-0028 的冻结授权视图支持主人网页和私聊接续。主人在群里近期说过的话需要少量跨端语境，群内引用及角色应答对象也需要保留各自归属。长期复制群原文会增加持久保存量，旁听超额记录的内存窗口还具有独立的可用期。

## 决定

- 网页与已配对主人私聊采用独立的只读补充块，最多选择准入时最近六小时的十条可信主人发言。每条正文与相应已确认角色回复各最多二百字符，按时序标明群名、时间、来源及引用作者、应答对象。
- 准入时沿用 `ConversationHistoryView` 固定范围，来源描述仅保存消息定位、授权代次与内容指纹。发送前复核账号、绑定、旁听代次及原文，后续配对和新消息不能扩大旧回合。
- 主人身份必须由接收时的明确主人标记和当前有效配对共同证明。缺失可信身份、时区或时间的旧记录跳过，解绑重配建立新的可见起点。
- 原文从既有会话、持久旁听和当前超额内存窗口读取。自然运行保存的旁听输入副本仅承担既有运行职责，投影以原旁听存储和当前窗口决定可用性。投影自身只读，网页和私聊持久记录不追加群原文副本。
- 角色回复使用确认投递投影，包括已确认的部分送达片段。发起者和选定回应对象各自保留，引用只提供已核验作者及来源关系。
- 补充块按既有完整请求预算参与选择。网页上下文检查采用同一材料。原始历史工具、普通摘要来源和后台自主上下文各自沿用原授权范围。

## 取舍

当前回合记录变更或撤权时，已有补充块失效，用户可在新回合读取新的合法材料。原文查询与发送前复核增加少量读取成本。准入只固定十条候选，等待期间新确认的回复留给下一次回合读取。

本决定补充 ADR-0028 的主人上下文范围，群消息仍由原线程持有，旁听每日保存额度与临时窗口继续生效。

# ADR-0036：按固定 Shiori 分离上下文窗口、宿主文档和语义引擎

状态：已采纳；维护者已批准 #302 完整单票方案。最后核验：2026-11-02。
事实来源：[批准规格](../specs/shiori-context-memory-alignment.md)、[固定源码调研](../research/shiori-context-memory-20261102.md)、[行为测试](../../tests/python/test_context_memory_parity.py)。

## 背景

旧设计把语义引擎开关、Markdown 维护和周期优化绑定，把结构化记录投影回长期文档，并在普通读取中修补文档或向量。覆盖成功与下游消费成功混在一起，工作摘要失败后可能重新提取已有记忆。硬超限的宽泛异常捕获将真实维护或摘要错误转成另一种正文请求。

本决定替代 ADR-0002 中不兼容的引擎/文档耦合、ADR-0024 的关闭记忆即免覆盖及宽泛 minimal 降级、ADR-0032 的 minimal 保留业务工具，以及 ADR-0034 中与本次稳定帧位置和覆盖顺序冲突的部分。原记录保留作为历史；当前执行授权与服务拥有桌面回合的 ADR-0035 继续有效。

## 决定

固定 Shiori `c14152ed225954a2a50da775075fe64dbf7b8b50` 为行为基线。Meido 保留 Web HTTP/SSE、SQLite 原消息、原角色和渠道授权及多协议 adapter，不引入上游插件宿主或本地 KV 服务。

1. 单一实际输入按稳定 system、合法历史/工作摘要、动态 context frame、当前输入和工具尾部排列。计量、发送、独立检查与手动压缩共享该输入。读取无文档刷新、向量修复或优化副作用。
2. 会话拥有 Markdown 覆盖与独立消费者进度。正常积压后台处理；窗口驱逐前等待精确完整前缀的覆盖，再生成摘要，最后发布有效摘要与切点。合法追加不使前缀失效。来源内容、归属或撤销改变使相应进度失效。
3. 成功的事件发布逐条确认，关系消费者只保留最新待处理内容。消费失败不撤销宿主覆盖；进程在外部效果与确认之间退出仍可能重试，不承诺跨进程恰好一次。
4. 软阈值失败在原请求严格小于硬预算时保留原请求。硬阶段的生成/校验/覆盖错误传播。只有上游允许的预算与供应商溢出路径进入 minimal，保留当前输入和真实已执行结果，移除业务 schemas，保留回复协议，不重放工具。
5. SELF/MEMORY 是宿主规范文档；HISTORY/PENDING 是追加产物。周期优化独立合并候选、更新自我认识。语义 CRUD 不整体改写文档。短文档提交共享锁，模型等待不占该锁；草稿取消中止模型请求，已进入短提交才延迟取消。优化代际停止立即恢复未消费候选，保留已提交 MEMORY。
6. 默认语义引擎使用独立 embedding 配置，身份为模型名与维度；不回退聊天凭据。兼容旧配置的一次性导入保留向量，失配保持数据并报告不可用，普通读取不重建。主人资料继续使用原独立配置入口。
7. 圆环与 `/compact` 调用同一控制器，允许阈值以下的可压缩完整前缀，不创建普通回合、聊天消息或情绪推进。角色/会话改变撤销操作归属；模型改变后重读当前计量。

## 代价与迁移

关闭语义引擎仍可能发生宿主文档模型调用，UI 明示这一语义。迁移需要首次备份空间；旧游标只一次导入，不持续双写。旧文档中的托管段正文成为规范文档的一部分，不丢弃手工段。兼容不明的旧向量空间保留，等待主人明确配置或主动管理。操作与回滚见[手册](../handbook/context-memory-migration.md)。

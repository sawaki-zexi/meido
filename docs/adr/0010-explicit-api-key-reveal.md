# ADR-0010：通过显式操作查看已保存的模型密钥

状态：已接受。主人于 2026-10-15 明确要求眼睛按钮可查看已保存的真实 Key。

最后核验：2026-10-15

事实来源：[`ApiKeyInput`](../../web/src/ui/ApiKeyInput.tsx)、
[`本地配置 API`](../../backend/app/main.py)、
[`接口测试`](../../tests/python/test_api_key_reveal.py)。

## 决定

- 模型和向量模型配置保存后，输入框以固定圆点表示已配置密钥。
- 常规配置读取和保存响应仍只返回 `apiKeyConfigured`，不自动加载真实密钥。
- 用户点击眼睛按钮时，通过独立 POST 接口读取当前连接的已保存密钥；模型连接
  按稳定 ID 读取，向量模型读取全局共享配置。响应声明 `Cache-Control: no-store`。
- 读取结果只用于当前输入框的临时明文展示，不自动写入配置草稿。隐藏、切换配置、
  测试或保存时清除明文展示；查看失败显示字段级错误，原配置不变。

## 原因与取舍

主人需要在本地设置中核对已经保存的密钥。此操作使真实密钥进入当前网页的短暂
展示状态，因此作为 [ADR-0001](0001-local-model-connection-boundary.md) 中默认脱敏
边界的明确例外。通过独立、按需调用的接口区分查看密钥和普通配置读取，避免页面
加载、保存或测试时自动返回真实密钥。

## 后果

本地后端仍是配置和密钥的权威来源，前端不持久化读取结果。密钥不得进入日志、
错误文本或模型上下文。此决定不增加远程共享或多用户权限模型。

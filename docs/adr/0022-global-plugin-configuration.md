# ADR-0022：插件全局启停与用途参数分离

状态：已采纳。2026-10-18 主人明确选择复刻 Shiori 配置实现。

2026-10-26：NovelAI 的重复公共/角色版本消费确认由 [ADR-0031](0031-novelai-plugin-readiness.md) 替代；其余插件及 CG 独立开关等边界继续有效。

插件是否启用属于应用；角色拥有数据和特定用途参数。替代旧规格中浏览器、主屏和桌面控制的每角色总开关、Coding 的重复角色总开关，不改变原生身份和来源边界。基础工具按 ADR-0021 默认提供。

已有全局服务复用原配置；缺少宿主开关的插件使用独立版本配置。所有执行处读取当前全局策略，运行冻结修订；撤销先于异步清理。视觉连接显式绑定，费用、CG、可信仓库、CLI、自主来源和投递目标不随普通插件启动自动授权。

取舍：主人无需给每个角色重复开插件；公共参数变化会影响所有角色，界面明确其全局作用。角色数据、有限用途许可仍分别归属角色，避免全局开关意外转移已有来源或成果。

具体行为与迁移见 [规格](../specs/global-plugin-configuration-spec.md)。

2026-10-19：强制显式视觉绑定部分已被 [ADR-0023](0023-screen-vision-chat-fallback.md) 替代；其他决策继续有效。

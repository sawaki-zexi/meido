# ADR-0023：屏幕视觉默认复用角色聊天模型

状态：已采纳。2026-10-19 主人在获知模型选择差异后继续要求完全复刻 Shiori 设置。事实来源：Shiori 4f266ae 的 roles/model_runtime.py；本决策替代 ADR-0022 的强制显式视觉绑定部分。

屏幕插件的公共视觉连接改为可选。未设置时，按原角色的有效聊天绑定解析（角色显式绑定优先，其次应用当前默认）；单次调用仍通过独立视觉请求返回严格校验摘要。已显式选定但不存在或不支持图像的模型必须报错，不切换其他模型。角色绑定失效时同样不回退到应用默认。

工具候选冻结解析后的确切模型 ID，调用时重新验证有效身份、内容和原撤销代。修改角色聊天绑定、应用默认或模型内容时撤销受影响观察并等待原资源收尾，不能让旧工具改投新模型。没有可用聊天模型不妨碍启用插件，但工具目录和真实调用明确返回配置缺失。

取舍：主人无需重复选择同一连接，设置行为与 Shiori 一致；更换聊天模型也会影响未单独绑定的屏幕分析。界面说明这一点。全局关闭、角色归属、仅主人桌面回合、图像不进聊天历史和消费边界保持原规则。

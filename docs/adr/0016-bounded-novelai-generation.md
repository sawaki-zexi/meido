# ADR-0016：有限消费的 NovelAI 生成

状态：已采纳，2026-10-16 主人在本次对话明确批准具体规格第 3 节；实施进行中。

2026-10-26：生图启用及重复版本消费确认部分由 [ADR-0031](0031-novelai-plugin-readiness.md) 替代；有限次数、单次 POST、来源与恢复边界继续有效。

## 背景与决定

生图具有消费、媒体归属和结果未知的风险，普通聊天模型凭据及通用网络重试不能承担该协议。采用独立 vault 凭据、默认关闭的有限许可和 300 秒 TaskRuntime 任务。每次 attempt 最多一个生成 POST；未知结果保留原 claim 和额度，不重试远端生成。

生成、历史、原来源媒体交付和重生成使用持久业务账本与唯一 outbox；收到完整响应后只恢复本地导入和投影。CG 仅由主人真实输入回合触发，显式绑定辅助模型并受预算、去重、冷却和取消约束。

## 取舍与授权

结果未知时牺牲自动重试的便利，避免重复消费；独立凭据和许可增加设置步骤，但隔离聊天权限与生成消费。批准覆盖实现、隔离本地构建和无费用 fixture；真实凭据、生成及费用另批。

事实来源：[具体规格](../specs/novelai-generation-spec.md)、[#171 实施计划](https://github.com/sawaki-zexi/meido/issues/171#issuecomment-6207490472)。批准不表示供应商调用或真实媒体验收完成。

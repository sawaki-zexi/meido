# ADR-0011：冻结授权目录与版本化工具激活

## 状态

已采纳。批准时间：2026-10-15。2026-10-16 的 #148 实现冻结候选、版本激活、持久化和受限服务修订协议；#159 / T12 实现预授权 stdio MCP 连接、按来源恢复及移除生命周期。当前接口与验证见[工具发现契约](../reference/tool-discovery.md)和 [MCP 服务契约](../reference/mcp-services.md)。

## 背景

现有能力快照在一次 Agent 运行开始时冻结，只包含已暴露工具；未激活的 deferred 工具被排除。复刻 Shiori 的 tool_search 需要在同一次模型推理中发现并调用新工具，同时不能通过重新解析最新角色配置扩大原始授权。

## 决定

1. 运行开始时冻结允许的候选工具、定义、角色与发言者作用域、可信插件和授权版本。
2. 另记录每次 provider 请求使用的不可变可见性版本。tool_search 只在已授权候选中检索，产生追加激活事实；结果持久化完成后，下一次请求才使用新版本。
3. 既有可见性版本不被原地修改，审计和工具调用关联实际版本。未激活工具的伪造调用得到明确拒绝和正确加载指引。
4. 主人预授权的 MCP 服务连接成功后，可以追加带父版本的能力修订；远端工具只能继承既有服务 grant、风险上限和角色范围，不能取得新的宿主权限。
5. 许可撤销和插件停用可中止执行。历史激活仅在当前定义、来源和授权仍有效时恢复，不复活旧权限。

## 取舍

保留完整授权快照，又获得同一运行内的按需发现。代价是要显式记录候选、可见性及 MCP 修订版本；保持固定 schema、等到下一次用户对话才加载会更简单，但不能满足已批准的 Shiori 行为。

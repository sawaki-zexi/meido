# ADR-0015：普通权限 Windows 桌面控制

状态：已采纳，2026-10-16 主人在本次对话明确批准具体规格第 3 节；实施进行中。

## 背景与决定

八个 Computer Use 工具需要可信窗口图像和真实输入，不能由现有主屏摘要代替。采用固定 MIT CUA 源码与最小可审计补丁，只构建普通权限 direct 驱动；不构建或连接 UIAccess helper。角色默认关闭，仅接受真实当前主人桌面来源。

宿主拥有私有 stdio 进程、跨进程输入 lease 和每 run 唯一观察。图像仅进入当前聊天模型下一请求，引用绑定来源和代次；关闭、撤权或失败须确认全部自有资源回收后释放 lease。

## 取舍与授权

普通权限模式无法控制更高完整性或锁屏桌面，捕获来源和坐标不确定时拒绝相应动作；代价是维护固定源补丁与构建证据，收益是明确进程所有权与权限边界。只在专用测试窗口进行原生验收；批准未授予任意真实应用操作、外部事务或 PR 合并。

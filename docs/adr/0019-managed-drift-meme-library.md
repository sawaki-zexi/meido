# ADR-0019：Drift 表情维护的受管库与图片预算

状态：已采纳，主人已在本次对话明确批准具体规格第3节；#191 实施中，尚未整体验收或合入 main。批准仅覆盖实现、隔离构建与无费用本地验收，真实模型、账号、平台事务和消费另批。

最后核验：2026-10-17。

## 背景与决定

普通聊天的 S04 已能读图和维护角色表情库；通用 Drift 的私有工作根、文本结果与现有许可不足以授权自主修改共享库或发送图片给模型。延续 [ADR-0018](0018-explicit-autonomy-and-drift-grants.md) 的自主身份与资源归属，新增独立默认关闭的表情维护用途许可，明确绑定主人指定的同一 Drift 视觉模型，不自动选择其他模型。

固定 builtin 的完整正文与支持文件共同认证有限模式声明。这个模式可以经窄库接口读图、分类编辑和复制本轮已冻结的当前角色素材，Shell 关闭时仍可运行；同名角色 Skill 和自定义 S06 不能继承这些能力。普通聊天 S04 保留自己的工具声明与权限。

一个角色库模块持有共享观察版本、读后 CAS、窄复制、实际存储预算和分阶段恢复。主人显式采用后，普通 FileTools 的库写与 Drift 共用短发布锁、版本和合计空间策略；未启用或停用后的普通编辑保持原合同。停用先封存旧代际，旧资源仍须退出，主人编辑不等待旧模型或未知恢复责任；再次启用须等待原资源退出并使用新代际。

图片只进入明确 Drift 模型的实际请求。沿既有 adapter 序列化与发送接缝，每次发送前按每个图片出现预留次数、实际编码字节、请求封装及输入估算单位，失败或取消不退款；正常与错误持久面使用安全投影，不保留原图或 base64。

## 取舍与边界

共享 CAS 与空间策略改变的是主人明确采用后的库编辑合同，因此需要独立许可和可解释的冲突反馈。旧未决责任保留并计量，但不使停用后的普通 S04 继续受新 CAS 或配额约束。

图片、metadata、manifest 和 SQLite 分阶段提交，无法形成跨文件系统和数据库的原子事务。恢复只核对原意图与已发生事实，不重跑模型、复制或覆盖主人后来编辑；已进入最终目录且可能被主人采用的文件不自动删除。同进程协作锁不构成对任意外部程序的 OS 安全边界。

直接图像请求增加内存和输入成本，8192 单位/次、每 run 最多 32768 单位是宿主输入估算预算，不是供应商 token 或费用硬上限。本地合成 provider 仅证明协议、字节与生命周期，真实识图质量及费用仍未验收。

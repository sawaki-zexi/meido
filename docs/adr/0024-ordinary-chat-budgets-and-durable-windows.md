# ADR-0024：普通聊天全局预算与持久工作窗口

状态：已采纳。2026-10-19 主人明确批准[高级设置方案第 3 节](../specs/advanced-settings-parity-spec.md)。实施验收状态以该规格为准。

事实来源：Shiori 固定 076a87b 的 input_budget、compaction 与 session/window；[七栏审计](../research/shiori-settings-implementation-audit.md)。

普通桌面与渠道回合冻结全局高级配置和有限模型请求预算；压缩请求也计入同一次预算。专用视觉、Coding、NovelAI、主动与 Drift 保持既有用途预算及许可。暂停创建子任务推进撤销代，恢复不能使旧运行重新获得创建或接续权；查询和取消继续可用。

配置及幂等操作结果在独立 SQLite 存储中原子保存，先查同 operationId 的原结果，再检查修订。保存队列保留失败草稿和不明结果，确认写入后的回读失败只重读。运行应用以已提交配置作可重复协调；计时器交接由原请求负责收尾，保存不立即触发优化。

采用显式模型容量及本地输入估算，在真实 provider 边界计量完整系统、记忆、schema 和消息。工作摘要与 cut 在 sessions.db 同事务条件提交，按角色、会话和来源 scope 隔离，后续回合及重启继续读取。提交依赖原文指纹、窗口版本、当前来源权限以及 MemoryEngine 的维护覆盖证明；尝试维护不等于覆盖。记忆暂停或来源无义务时明确 not_required。

原始历史保留。历史修改/撤销使受影响窗口失效，角色删除的回滚恢复原窗口；备份含同一 SQLite 表，读取时仍验证当前来源。更换模型重新计量，不删除合法摘要；未知容量仅停新压缩并保留兼容原文尾部及已有摘要。

取舍：持久窗口增加历史生命周期的维护责任，但避免跨回合反复付费生成同一摘要。服务商 tokenizer 各异，因此估算保留安全余量并明确限制；超大完整轮或摘要请求前缀不能装入时明确失败，不无限分块、重试或静默丢原文。有界诊断代替上游完整 payload 快照，保持既有凭据与原图不额外进历史的约束。

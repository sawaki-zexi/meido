# ADR-0021：默认提供基础工具

状态：已采纳。2026-10-17 主人明确要求参考 Shiori 默认内置工具，并对 Shell 默认执行方案回答“按照 shiori 来就行”。

## 决定

默认基础工具不再采用每角色 enabledTools 的逐项 opt-in。旧角色与新角色使用同一宿主清单；保留字段用于兼容与扩展，不让旧空列表隐藏基础能力。特殊插件继续使用独立启停、依赖与用途许可。

普通主人 Shell 使用固定平台 shell，取消旧 enabled/allowedCommands 准入；仍以角色 workspace、最小环境、运行预算和 owned 进程树执行。受限子任务和自主用途保持独立 argv 白名单，不继承这项普通聊天授权。

此决定替代 [ADR-0004](0004-role-scoped-shell-tool-boundary.md) 第2项及普通主人执行的 argv 白名单部分，保留其资源、环境和非沙箱边界；同时替代 #163 的基础逐项勾选方案。增加默认可用性是主人本次明确选择，不将其解释为账号、付费生成、自主发送或实际发布批准。

## 取舍

角色能直接工作，避免安装工具后仍看不见；代价是普通主人模型拥有本机 Shell 执行能力。界面明确默认提供与插件暂停的区别；实际来源和外部服务的业务许可继续在工具执行处校验。

事实来源：[具体规格](../specs/default-builtin-tools-spec.md)、Shiori 固定4f266ae的 common/meta 工具注册和平台 Shell runner。

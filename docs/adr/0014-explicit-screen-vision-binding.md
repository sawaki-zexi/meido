# ADR-0014：显式视觉绑定与按需主屏观察

状态：已接受。批准时间：2026-10-16。

## 背景

角色主聊天连接已经拥有多种协议的图像编码能力，但按需观察主屏还涉及桌面可访问性、独立图像用途、明确授权和可终止的采集。把未绑定的视觉用途自动回退聊天连接，会让主人无法判断画面将发往何处；直接同步采集或不可终止的线程也不能保证停止和撤权完成时资源已收尾。

## 决定

1. 角色以 `agentConfig.screenPerception` 保存默认关闭的开关和显式 `visionModelConfigurationId`。可以由主人明确选择与聊天相同的已保存 ID；不自动使用聊天或 active ID，也不复制模型密钥到角色。
2. 只允许当前角色由主人发起的桌面回合按需观察主屏。模型空对象输入不能选择角色、连接、采集范围或授予权限；渠道、后台与定时运行不自动获得观察资格。
3. Windows 主屏由固定 Pillow 短命进程采集，检查交互会话、输入桌面与尺寸，使用有界内存管道。父模块拥有帧校验、deadline、终止/wait、并发名额与取消；不落临时截图或持久观察任务。
4. 独立视觉请求复用现有模型 adapter，使用固定中性 prompt、单帧和空工具列表，不带角色设定、聊天、记忆或技能。只接受严格两字段 JSON，再返回 `available/interface_summary/activity_key`；原图不进入主聊天、历史、普通审计或工具图片结果。
5. 角色开关、视觉连接变更/删除、停止与角色删除均使旧观察失效并等待资源收尾；原绑定和配置版本在上传前及结果发布前重新核验，不用新连接或缓存帧代替失败观察。

## 取舍

短命进程增加解释器启动与 IPC 成本，但能够终止真正拥有原图的采集执行。现有 adapter 保留多协议/认证与图像支持，避免另造单协议 gateway；某个模型是否支持视觉仍在实际请求中验证。摘要文字可能进入正常工具历史，原图隔离不等于摘要绝对准确或绝对脱敏，也不承诺远端数据撤回或安全擦除。

本决定独立于 Computer Use 和桌宠 Electron/PySide6 宿主选择，不授权控制桌面或调用未选择的付费视觉服务。固定预算、错误协议与公开验收以屏幕规格为准；架构批准不替代实现验收和最终 PR 合并批准。

# 使用默认内置工具与插件

状态：当前。最后核验：2026-10-17。事实来源：[具体规格](../specs/default-builtin-tools-spec.md)、[ADR-0021](../adr/0021-default-builtin-tools.md)、[工具目录](../reference/tool-capability-catalog.md)。

文件读写、网络查询、消息原文、记忆、工具发现、Shell/后台任务、子任务、时间任务和桌面推送默认随角色提供。新旧角色均无需逐项勾选；旧 enabledTools 空列表不隐藏默认工具。

在“设置 → 工具与插件”选择角色，调整 Shell 和子任务预算，点击“查看实际工具”检查下一次桌面对话的声明与依赖。普通 Shell 使用 PowerShell 7 或 /bin/sh，固定角色 workspace 和有限环境；不是操作系统沙箱。“受限任务的命令许可”仅控制脚本子任务和软时间任务，不控制普通对话。

打开“设置 → 工具与插件”，选择角色启用或暂停浏览器、屏幕、桌面控制、生图、Coding、桌宠及自主功能。凭据、模型连接和组件使用各自设置；停用保留已有配置。部分自主/桌宠操作沿其独立明确按钮保存。

默认提供不代表依赖就绪，也不自动执行。宿主网络或全局记忆关闭时显示实际原因；缺少 PowerShell 7、浏览器组件或服务配置时明确报错，不回退账号或模型。MCP 服务仍需 trust/grant，不继承其他角色和自主来源权限。

每个运行冻结允许候选；tool_search 只追加原许可内 schema。兼容字段不撤销普通默认能力；停止使用已有停止按钮、cancel_schedule 或插件启停。

# 使用默认内置工具与插件

状态：当前。最后核验：2026-10-18。事实来源：[具体规格](../specs/default-builtin-tools-spec.md)、[ADR-0021](../adr/0021-default-builtin-tools.md)、[工具目录](../reference/tool-capability-catalog.md)。

文件读写、网络查询、消息原文、记忆、工具发现、Shell/后台任务、子任务、时间任务和桌面推送默认随角色提供。新旧角色均无需逐项勾选；旧 enabledTools 空列表不隐藏默认工具。

在“设置 → 高级 → 运行设置”点击“设置”展开角色参数，调整 Shell 和子任务预算，点击“查看实际工具”检查下一次桌面对话的声明与依赖。普通 Shell 使用 PowerShell 7 或 /bin/sh，固定角色 workspace 和有限环境；不是操作系统沙箱。“受限任务的命令许可”仅控制脚本子任务和软时间任务，不控制普通对话。

打开“设置 → 插件 → 功能插件”，直接启动或关闭全局插件；无需先选角色。点击“设置”修改公共参数，保存参数不会启动插件。屏幕感知先明确选择视觉连接，再回列表启动；不会自动跟随聊天模型。默认工具不出现在列表，已启用不等于原生进程正在运行。

CG、桌宠、自主策略、编程用途在各自插件设置中展开“角色参数”。关闭插件保留连接、预算、动作包和角色偏好，正在执行的资源先撤销后收尾；收尾失败显示“等待资源收尾”，可重试关闭。浏览器会话与文件、任务、生成结果仍属于原角色。

NovelAI 手动生成及每角色日额度使用公共设置，明确确认当前版本的有限消费后才接受请求；修改参数或凭据需重新确认。CG 按角色独立授权，不随公共手动许可开启。旧角色总开关不会自动迁移为全局授权，已有服务开关保留。详见 [全局插件配置](../specs/global-plugin-configuration-spec.md)。

默认提供不代表依赖就绪，也不自动执行。宿主网络或全局记忆关闭时显示实际原因；缺少 PowerShell 7、浏览器组件或服务配置时明确报错，不回退账号或模型。MCP 服务仍需 trust/grant，不继承其他角色和自主来源权限。

每个运行冻结允许候选；tool_search 只追加原许可内 schema。兼容字段不撤销普通默认能力；停止使用已有停止按钮、cancel_schedule 或插件启停。

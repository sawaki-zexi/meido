# 查看和管理角色记忆

状态：当前；最后核验：2026-10-20。事实来源：[记忆页](../../web/src/features/memory/MemoryPanel.tsx)、[行为验证](../../web/src/features/memory/MemoryPanel.test.tsx)。

打开角色对话，点击右上角的记忆图标。页面仅展示当前角色的记忆。

- “记忆条目”按本地记录日期分组，用时间线展示有效记录，保留服务返回顺序。输入关键词后搜索，或选择类型；“筛选”可按状态、领域和语义索引查询。列表按每页 20 条读取。
- 点击一条记忆就在原位置展开来源和操作，再从来源跳回原消息或打开渠道来源窗口。再次点击该条或在详情内按 Escape 可收起。没有消息来源的手动记录不会出现定位按钮；完整时间、权重等字段在“更多操作与信息”里查看。
- 点击“记住一件事”在居中表单里手动记录内容。保存失败保留输入，可以重试；没有保存的新增记录可取消。
- “编辑记录”调整状态、发生时间等管理字段。摘要和类型保持原记录；来源 JSON 等字段在“高级字段”中，普通查看无需编辑。
- “记忆文档”只读查看长期记忆、自我认识、共同经历、近期上下文、待整理内容和已有整理日志，用文档选择框切换。

要处理多条记录，先进入“批量管理”，再勾选当前页。切换筛选或分页会清空选择；删除前会再次显示选中数量。详情的“更多操作与信息”中可忘记、拒绝或删除单条记忆，取消确认不会提交操作。

键盘可切换两个视图，展开详情时仍可访问页面其他操作。编辑、确认或来源窗口打开后，Tab / Shift+Tab 留在当前弹层，Escape 关闭当前层。来源窗口关闭后回到原记忆条目，随后按 Escape 可收起详情。正在保存时先等待结果；失败的输入会保留。

记忆条目与记忆文档沿用既有服务和整理流程，网页不直接写文件或数据库；界面成功保存不意味着已验证所有真实模型服务。

# 创建和管理角色时间任务

状态：本地实现，待总 PR #162；最后核验：2026-10-16。
事实来源：[时间任务契约](../reference/owned-schedules.md)与公开HTTP/角色表单测试。

1. 时间任务默认随角色提供，新旧角色无需逐项勾选。创建、查询和取消仍绑定真实主人请求及原来源。
2. 在当前角色对话提出具体要求，例如“十分钟后提醒我休息”“每天上海时间九点发送这段文字”，或“明天九点查询已许可网页并回报”。固定文本用instant，到时执行用soft。
3. 检查返回的计划ID、时区、下次时刻和剩余次数。相对时间以宿主接收消息为起点，推理延迟不会把计划推后。
4. 在原来源查询真实执行和送达状态。pending/uncertain不代表送达；不确定的重复计划会阻塞。确认平台状态后可取消并明确创建新计划。
5. 取消提供完整ID、至少8位唯一前缀或精确名称；同名可取消本来源全部匹配，重复取消安全。

停止已创建计划使用 cancel_schedule，旧工具列表变化不再撤销默认时间任务。运行仍校验原角色、来源、目标与插件许可。

DST歧义时刻使用带明确offset且符合所选时区的ISO；不存在时刻拒绝。重启后循环历史slot跳过，单次只在五分钟宽限内补一次，不集中补发。

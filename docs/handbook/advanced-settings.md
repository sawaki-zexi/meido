# 调整普通聊天与上下文预算

状态：当前实现；本地夹具验收，真实服务消费未验。最后核验：2026-10-19。事实来源：[高级页](../../web/src/features/settings/AdvancedSettings.tsx)、[配置](../../backend/app/advanced_settings.py)、[请求边界](../../backend/app/agent_runtime/context_provider.py)、[决策](../adr/0024-ordinary-chat-budgets-and-durable-windows.md)。

打开设置 → 高级，修改五组十三项。有效修改自动串行保存；输入过程中会显示等待保存。离开设置会安排最后一份合法草稿保存。失败保留当前草稿，结果不明时使用“重试保存”继续原操作；其他窗口已修改时，可选择放弃草稿并重新读取，不能直接覆盖。草稿不写入浏览器持久存储，未保存失败后刷新会丢失本地草稿。

“单次回复长度上限”和“单次任务最多步数”作用于普通桌面/渠道聊天的新运行。摘要请求也计入步数。专用视觉、编程、生图和自主任务继续使用自己的预算与许可。“按需工具发现”对应 Shiori 高级中的“联网搜索”实际语义：关闭后直接展示已授权工具，不会关闭 web_search/web_fetch 或增加权限；MCP 成功连接并提交工具结果后，其获准工具直接进入下一次请求，无需 tool_search。暂停创建子任务仍允许查询、取消已有任务，恢复不使旧运行重新获得新建或接续权限。

设置 → 模型 → 编辑连接，可填写实际上下文容量和可选压缩阈值；阈值必须小于容量。容量还要容纳当前回复预留和安全余量，不足时请求前报错。未填容量时不新增自动压缩，继续使用完整用户轮组成的有界原文尾部及已有合法摘要。

压缩按完整系统提示、记忆、工具 schema 和消息的本地估算触发；ASCII 约三字一 token，非 ASCII 每字两 token，真实图像使用独立固定预算。估算不是服务商 tokenizer。摘要保留当前轮和完整工具链，不额外发送原图；前缀或必留块超容量、摘要不合法、维护未完成或取消时不会推进窗口。遇到超大前缀可改用容量更大的连接；程序不会无限分块或重试。

“记忆整理消息基数”向上对齐 4 后取半，作为 Markdown 最近保留数；它不是 token 容量。后台整理必须同时通过记忆总开关和高级整理开关。改间隔或启停只安排正常计时，不因保存立即调用模型。

开发者模式启用并保存后，新普通聊天记录请求次数、压缩次数、模型 ID、工具数、输入估算和耗时。通过高级页“刷新运行诊断”查看，最多返回最近 20 个运行中的相关记录；关闭后不生成或展示新增诊断。该入口不额外保存原图、密钥和完整请求。

配置与幂等结果位于数据目录的 `advanced-settings.db`，摘要/窗口状态位于 `sessions.db` 的 `context_windows` 表，原始消息保留。现有 [备份脚本](../../scripts/local-runtime/backup-meido-data.py)复制整个数据目录，并对 SQLite 使用 backup API，因此包含两者。不要只复制数据库文件的一部分表；恢复旧窗口后仍检查当前来源授权。角色删除回滚恢复对应窗口，修改或撤销摘要来源会使受影响窗口失效。

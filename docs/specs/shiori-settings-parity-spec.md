# Shiori 全设置复刻

状态：部分实施；调研完成，第一批高级十三项、模型容量与持久压缩已获批准并完成无费用本地验收，以下其余差距仍为计划。最后核验：2026-10-19。Parent：#137，已有相关工作在 Draft PR #196（main 为目标）。

事实来源：[七栏源码审计](../research/shiori-settings-implementation-audit.md)，固定上游 076a87b；Meido 调研基点 6035dfd，第一批当前实现见[高级设置规格](advanced-settings-parity-spec.md)。本文描述后续结果与顺序，不把既有展示框架算作完整功能。具体跨功能决定在实施前单独确认；不以本规格授权真实账号、费用、安装或发布事务。

## 目标与交互

复刻模型、记忆、外观、高级、我的身份、插件、关于七栏的实际配置行为。每个控件必须有真实消费者、校验、持久化、失败恢复及可观察结果。侧栏和子页顺序、分组卡片、开关、详情返回、中文辅助说明和保存反馈参照上游；配色统一使用 Meido 已有樱粉语义变量，1650/1070/390px 下保持字段和控件对齐。

普通配置采用串行草稿保存：有效修改排队，更新期间保留后续编辑；冲突不覆盖别人设置，错误不丢草稿，成功后回读失败只重读。新建尚不完整的模型留在本地草稿。测试连接、账号配对、可信包确认、原生服务启动及消费许可仍由明确动作触发。密钥继续使用 Meido 按需读取与既有 vault，不把明文保存到浏览器或普通列表响应。

既有服务存储是各自参数的唯一事实来源，不把模型、插件、记忆和账号重写成互相覆盖的大 JSON。可以复用保存队列和状态展示，但跨域写入不宣称具有数据库事务性；确实需要联动的模型删除与用途解绑必须先形成可恢复计划。

## 插件专属内容

上游内置包为 11 功能、4 渠道、8 系统组件；详单和字段以审计为准，不在设置里用静态名字伪装可用包。

- Browser Use 已有 headed/timeout；Computer Use 需要把 5–120 秒的公共超时接到真实原生操作，关闭后仍完成输入 lease 与进程收尾。
- Herdr 展示真实可用配置和缺失 session 状态，保留已批准的 owned-mode、600 秒和可信仓库/CLI 许可；不照搬 FullAccess。
- NovelAI 区分默认模型、文生图/图生图能力、角色 CG 与消费许可。保存默认值不能触发生图或授予消费；缺失的参数必须接到真实请求校验后上线。
- 桌宠全局页接入语音开关、热键、麦克风、ASR/TTS provider；动作包和角色绑定仍在角色资产流程。GPT-SoVITS/SenseVoice 要完成安装环境、启动/停止、健康、实际音频流及取消清理，不能用服务地址输入框冒充完整语音链路。
- 渠道复用已有各平台设置及身份边界；系统组件只有真实消费者才能展示配置。Story 是独立工作区及产品行为，不能只加一个插件开关就算完成。

这些涉及包信任、麦克风、原生依赖和主应用宿主的新架构尚未获批准；各自具体设计应复用现有相关 Issue，未覆盖的闭环再建垂直 Ticket，避免与已有 PR 重复实施。

## 实施顺序与验证

1. **高级 + 模型容量 + 持久压缩**：按具体方案补齐普通聊天的真实预算、上下文窗口及高级页保存；这是下一批实现。先用 localhost provider 夹具证明每项运行效果，覆盖跨回合/重启、工具链配对、取消、失败和来源隔离。
2. **基础设置一致性**：模型草稿与依赖删除、记忆语义及迁移、流式作用域、身份确认；共享保存队列的交互，在各权威存储边界内逐项迁移。每项均以失败不丢草稿、旧响应不覆盖新编辑、刷新仍一致验收。
3. **插件配置与生命周期**：先补已有插件确实支持的公共参数，再落实动态 schema/包生命周期的具体设计；关闭可撤销新执行、待收尾不能重启、环境变量引用不展开回写、仅目标插件参数变化。
4. **语音、看板娘及桌面专属能力**：单独列出可演示闭环，明确资源许可、原生宿主和支持状态后实施；关于页更新与 Story 工作区不混入普通设置改动。

现有 PR #196 是基础工具/全局配置前置，不从该功能分支派生堆叠 PR；沿用当前已授权范围整理调研和提案。新增独立 Ticket 的实现按 AGENTS 从最新 main 建分支，前置未合入时等待，不宣称未合并代码在其他分支可用。

交付每一闭环时进行最小相关行为测试、受影响类型检查/构建、桌面与窄屏浏览器验收，以及规范/规格两轴审查；不重复未变化部分的检查。真实模型、账号、平台发送、安装和发布的验收另计，夹具通过不能标为真实服务通过。

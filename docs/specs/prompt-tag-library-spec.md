# 角色提示标签库

状态：当前（#250 / PR #252 已实现，待合入）。
最后核验：2026-10-26。
事实来源：`web/src/features/novelai/PromptTagManager.tsx`、`usePromptTags.ts`、`PromptTags.test.tsx`；Shiori `d149de7f052f77c5bb88d4d1393d48dce1870875` 的 `plugins/novelai/ui/PromptTagLibraryPanel.tsx`、`PromptTagEntryEditor.tsx`。

角色库采用“浏览卡片 → 独立编辑”的流程。搜索覆盖完整的最多 250 个条目，名称、关键词及正负提示词支持大小写和全角兼容查找；分类、内容分级、启用状态组合筛选，显示结果数。加载不完整或读取期间修订变化时提示重查，避免把部分结果当成完整库。

新建或点击卡片进入编辑页，左侧管理参考图，右侧填写名称、分类、关键词、正负提示词和内容分级。参考图只帮助辨认条目，不参与供应商参考图条件控制。顶部提供返回、恢复已保存内容和保存；没有修改时禁用还原和保存。保存后留在编辑页，并以服务端保存值更新还原基线。

返回列表保留当前草稿和筛选，再点同一张卡片或“继续编辑”会恢复它。明确选择另一张卡片或新建时开启对应草稿；不维护多个条目的未保存草稿。角色切换清空本地状态，旧角色迟到的读取、保存、上传、删除或预览结果不得写入新角色界面。

删除需确认，取消不发送删除请求；删除失败时保留确认对象并显示错误。实际删除成功后退出确认，即使随后的列表重读失败，也应通过刷新恢复列表。本地匹配预览保留为可展开的次级区域，不调用生图服务。

本组件继续使用原有 `roleId` / `expanded` 接口，兼容聊天抽屉和工作台入口。完整页面工作台由独立的 [PR #248](https://github.com/sawaki-zexi/meido/pull/248) 承担，不将未合并实现复制进当前分支。搜索是 Meido 的新增能力，Shiori 当前卡片页没有搜索筛选。

验证：NovelAI 前端回归 68 项通过，其中标签交互 11 项；覆盖全库查找、组合筛选、失败重读、草稿恢复、CRUD、删除确认/失败和角色 A→B→A。TypeScript、网页和桌宠构建通过。两轴审查均已关闭发现。隔离浏览器组合预览验证桌面与窄屏以及标签草稿往返工作台，均使用假 API，无真实生成消费。GitHub CI 以 PR 最新提交检查为准。

# 当前会话上下文独立检查

状态：当前；维护者于 2026-11-01 批准单票交付。
最后核验：2026-11-01。
事实来源：[Issue #297](https://github.com/sawaki-zexi/meido/issues/297)、[实现](../../backend/app/context_inspection.py)、[行为测试](../../tests/python/test_context_inspection.py)。

## 问题与结果

历史消息上的 `contextUsage` 只描述当时的一次模型请求。主人修改模型、角色或工具后，需要不发送消息就能了解当前保存会话的输入占用。现有圆环独立读取当前角色实际聊天模型下的状态。按维护者 2026-11-01 的展示纠正，沿用 Shiori 的 20px SVG 细环、30px 触达区与 280px 两行提示：用量／容量／百分比／来源，以及当前状态或原因；不展示预算明细表和重新检查按钮。

## 行为

- 打开聊天即可检查，悬停、聚焦或触屏点击圆环显示简短提示并按需重读；回复结束、模型或设置变化、返回聊天、恢复网络后刷新。快速切角色或模型时取消旧读取，旧结果不能写入新视图。
- 使用正常请求的提示渲染、授权历史、工作摘要、原文窗口工具恢复、厂商规范化与预算算法；包含已保存图片和工具交换。计量来源保留 `actual`、`anchor_delta`、`local`。
- 不包含草稿、未发送附件或新输入才会触发的检索及反应。这个数值不是下一次回复的最终输入，也不是累计消费。
- 检查不开始回复、调用模型或工具、维护记忆、压缩历史、发布工具可见性或写用量锚点。现有窗口失效时只读回退原文，不写失效水位。
- 回复、角色清理或记忆维护时显示忙碌；同角色、同会话、同模型保留最近有效用量并注明是上次用量，身份变化立即清除。模型未配置、读取失败和变化中返回明确原因。接口保留可靠输入估算，容量或用量未知时圆环无填充，提示用量未知。
- MCP 使用当前配置下已有的观察目录。需要恢复的服务目录未观察或已过期时明确暂不可用，不为了展示预算启动外部服务。

## 范围与验证

本票复用 #282 的校准、#291 的异步准备、#293 的回复生命周期，不新增运行器、全局锁、永久状态表、持续高频轮询或数据库迁移。不包含手动压缩、`/compact`、工具容量上限调整、Herdr 和插件内核重写。

API 与真实 SQLite 测试检查保存历史、摘要水位、运行、审计及校准没有变化；覆盖图片、工具、工作摘要、模型变化、未知容量、忙碌和并发失效。前端验证刷新、取消、来源说明和失败恢复；隔离浏览器验证聊天入口、模型切换、回复完成及网络恢复。测试不连接真实渠道或付费模型。

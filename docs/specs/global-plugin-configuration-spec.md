## 用户结果

设置里的插件列表不再先选角色。基础工具不展示开关。浏览器、屏幕感知、桌面控制、编程委托、NovelAI、待办、自主行为和桌宠显示全局启停及设置入口。全局关闭使所有角色的新工具调用和自主动作停止；保留角色数据、参数和原任务的收尾责任。

参数保存和插件启停相互独立。浏览器的显示窗口/超时、屏幕感知的显式视觉连接是公共参数。视觉连接不回退到聊天模型。已有 NovelAI、Coding、待办全局服务开关仍是唯一事实来源，不另造一套副本。

只有确实需要角色差异的用途保留角色配置：CG 辅助模型和有限许可、提示标签、桌宠动作包、主动策略及来源/发送目标、编程的可信仓库和 CLI 授权。它们放在相应插件的设置中，不再给所有插件套一个“配置角色”选择器。编程的角色 enabled 和浏览器/屏幕/桌面控制的角色 enabled 退为兼容字段，不再控制普通聊天插件启停。

手动生图许可与每角色日额度移到 NovelAI 公共参数；全局消费确认不能授予角色 CG 许可。凭据和参数变化撤销旧消费确认。插件的启动不自动确认费用、补视觉连接、授可信仓库、启用自主模式或选择桌宠动作包。

## 数据流与兼容

新增宿主插件配置持久保存缺少全局开关的插件及参数，每插件独立 revision。启停只改变 enabled；参数提交只改变明确提交的字段。过期 revision 返回 409，严格校验未知字段、类型和体积。先持久撤销当前代的权限，再等待原生资源收尾；收尾未确认时保持不可用，界面可以重试关闭，不能直接启动。重启恢复收尾责任。

运行时使用全局插件策略，角色文件保留原值且不批量改写。所有角色共享插件可用性，但浏览器会话、工作目录、记忆、任务与图片归属保持角色隔离。运行冻结插件修订，关闭后再启动不能复活旧工具调用。原生主屏、窗口输入、任务和自主来源仍执行既有身份、预算、版本与进程回收约束。

新全局开关默认关闭。旧角色开关不自动汇总为全局授权，不复制费用确认、凭据、视觉连接或仓库授权。已有服务开关保留。历史字段仍可读，目的型许可仍在原存储中保存。

## 验证

沿用现有本地 HTTP、工具实际调用和 React 界面边界进行红绿验证：两个角色共享插件开关；参数与开关互不覆盖；重启/过期编辑/收尾失败可恢复；旧角色 opt-in 不绕过全局关闭；关闭再启用拒绝原冻结调用；保留浏览器和角色数据；消费确认与 CG 独立。浏览器夹具覆盖全局列表、插件专属角色设置、失败反馈与窄屏；不进行实际账号、模型消费或外部平台事务。

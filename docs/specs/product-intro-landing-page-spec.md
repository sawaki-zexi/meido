# Meido 项目介绍落地页产品规格

状态：当前

事实来源：`web/src/landing/`、`web/public/landing/`、Issue #22–#24
最后核验：2026-10-01

## 1. 目标

制作一个静态、可交互的 Meido 项目介绍页。访客先看到带有角色形象的标题画面，开始后进入 galgame 风格的对话流程，由女仆通过可选主题介绍项目。

落地页用于介绍项目，不承担角色管理、真实聊天或模型调用功能，也不依赖现有前后端 API。

## 2. 核心流程

```text
标题画面
  -> 任意键、点击或触摸开始
  -> 转场
  -> 开场对白
  -> 项目模块选项
  -> 选择模块并阅读介绍
  -> 返回模块选项
  -> 选择“没什么想问的了”
  -> 结束语
  -> 查看 GitHub / 重新开始 / 返回标题
```

## 3. 标题画面

- 全屏使用用户提供的明亮客厅场景图作为背景，画面中叠加 Elysia 宠物形象。
- 显示项目名称 `meido`。
- 显示动态提示“按任意键开始游戏”。
- 键盘任意键、鼠标点击或触摸屏幕均可开始。
- 开始后播放短暂转场，再进入对话场景。
- 标题画面不显示模块卡片或真实聊天输入框。

## 4. 对话场景

- 标题页、开场、所有模块介绍和结束语统一使用同一张用户提供的客厅场景图作为背景；第一版不切换其他背景图。
- Elysia 宠物精灵图从本机 Codex 宠物资源中提取所需帧，作为透明背景角色立绘使用。优先挑选适合常驻展示的站立帧，并可使用现有表情/动作帧表达欢迎、讲解和告别状态。
- 场景背景铺满视口，角色立绘与底部对白框分层显示。
- 对白框显示说话者名称和对白；长对白应换行，不得遮挡选项或溢出视口。
- 对白以逐字效果出现。对白尚未显示完整时，推进操作应先显示整句；完整后再次推进才进入下一句或选项。
- 角色使用温柔、恭敬、认真、略带羞涩的女仆语气，称访客为“主人”。角色需作为 Meido 的原创讲解形象呈现，不直接复用既有作品的台词或角色设定。

## 5. 对话与选项

### 5.1 开场

开场对白介绍 Meido 是什么，并邀请访客选择想了解的主题。开场结束后显示主题目录。

### 5.2 主题目录

第一版包含以下选项：

- 角色系统
- 持久会话
- 流式对话
- 模型接入
- 本地架构
- 没什么想问的了

各模块选项对应项目的大主题。访客选择后播放该主题的对白介绍；介绍结束后回到同一组选项。访客可以反复选择和浏览不同模块，已读主题可以显示已读状态。只有选择最后一项“没什么想问的了”才进入结束语。

### 5.3 内容准确性

- 每个主题用约 3 至 5 句对白说明用户能理解的结果或项目设计。
- 内容以项目当前代码和已确认规格为准。
- 已实现能力与规划中能力必须明确区分。特别是模型设置目录、多服务商配置等尚未完成的能力，不得描述成当前已可使用。
- 主题内容放在可维护的静态脚本/数据中，不与对话界面结构耦合。

### 5.4 结束选项

- “没什么想问的了”是目录中的最后一个选项。
- 选择它后进入结束语，不再回到主题目录。
- 结束语感谢访客了解 Meido，并提供“查看 GitHub”“重新开始”“返回标题”等入口。
- GitHub 入口使用项目的正式仓库地址；正式地址未配置时不显示失效链接。

## 6. 对话控制

- 点击对话区域或按 Enter / Space 推进对白。
- 提供自动播放、跳过、对话记录、设置和返回标题控制。
- 设置至少允许调整文字速度，并允许关闭动态效果。
- 支持系统减少动态效果偏好；关闭动态效果时，逐字效果和场景转场应直接完成。
- 选项必须是可聚焦、可键盘操作的按钮，并清楚显示当前焦点。

## 7. 视觉素材

- 背景：用户提供的明亮客厅场景图。当前版本统一用于标题页和所有对话场景。
- 角色素材：`C:\Users\Elysia\.codex\pets\elysia\spritesheet.webp` 中的 Elysia 宠物帧。该精灵图是动画帧集合，不是单张 galgame 半身立绘；实现时应从中裁切独立帧并保留透明通道。
- 实现时应将实际使用的图片资源放入项目可随构建发布的静态资源目录，不让网页依赖开发机器上的绝对路径。
- 对话框、选项和弹窗使用白粉半透明色调，文字保持足够对比度。
- 后续替换背景或角色图不应改变剧情流程。

## 8. 范围边界

本落地页是静态体验，不包含：

- 真实 AI 对话、后端请求或流式模型调用
- 角色、会话或用户数据持久化
- 会改变后续剧情结果的分支剧情
- 背景图库、立绘编辑器或上传管理功能
- 将现有角色管理/聊天应用改造成 galgame 界面

## 9. 验收标准

- 首屏显示客厅场景背景、Elysia 角色形象、`meido` 标题和“按任意键开始游戏”提示。
- 键盘、鼠标和触摸均可从标题画面开始，且开始后进入短转场和开场对白。
- 对话页面背景始终为同一张指定客厅场景图，Elysia 立绘显示在对白框之外且透明背景正常。
- 对白逐字显示；推进时可先补全当前句，再进入后续对白。
- 开场后可从目录选择任一项目主题阅读；每段介绍结束后回到同一组选项，访客可继续选择其他模块。
- 目录最后一项“没什么想问的了”会进入结束语及结束操作入口。
- 访客可查看对话记录、切换自动播放/跳过、调整文字速度并返回标题。
- 桌面和窄屏视口下对白、选项、立绘均不互相遮挡；关键操作可通过键盘完成。
- 页面可独立运行，不要求 Meido API 或模型服务可用。
- 项目介绍不会把规划中的功能说成已实现能力。

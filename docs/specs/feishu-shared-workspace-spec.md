# 飞书共享上下文

状态：当前设想。更新于 2026-11-19。

飞书知识库用来把主人愿意与 AI 共享的信息整理成可查阅的文档。现在先由 Codex 按需使用这份资料。以后接入其他 Agent 时，同一份资料可以作为协作的中间层，让各自独立工作的 Agent 查到相同的背景和规范。[重构决策](pi-refactor-decisions.md)

## 保存哪些信息

- **现在的我**。个人背景、近期重点、长期目标、通用偏好，以及当前的学习进度。
- **共同说明书**。跨任务适用的约定，例如资料放在哪里、如何引用，以及主人希望 AI 遵循的通用规则。
- **资料索引**。供以后查找的笔记、文档和工具说明。长期有用的结论可以简记在对应主题下，并附上来源。

## 怎么使用

主人直接在 Codex 里交代任务。Codex 需要背景时读取已获授权的页面或章节，在原会话或工作区完成任务。主人可以直接编辑飞书，也可以明确交代 Codex 更新某个主题。任务细节保存在原会话或工作区，项目索引和决策放在项目侧，各角色的记忆由各自的运行环境保存。

例如，主人在 Codex 里问「按我的当前进度，给我一个 TypeScript 练习」。Codex 可以读取飞书里对应的学习进度，给出符合当前水平的练习。主人想保存这次进展时，可以直接说「把这次练习的结果补到学习记录」。

当前范围为共享资料的整理和按需读写。周报、通知、待办、任务领取、Agent 工位和自动更新均退出本期范围。

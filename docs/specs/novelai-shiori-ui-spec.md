## 用户流程

- 工作台左栏选择角色、切换正负提示词、选择底图和尺寸；绘图偏好从角色旁的设置入口展开，完整模型、采样、种子、多图及交付选项按需查看，生成按钮始终容易找到。
- 上传/选中底图后可看到图片、调整重绘强度与噪声、换图或移除。底图仍必须是当前角色允许的附件；历史参数复用继续保留既有模式与来源。
- 右栏以大图和底部缩略图为主，生成中、无结果和失败都可辨。下载、多图选择、参数查看、复用、显式重生成以及不确定结果说明保留；图片参数默认收起。
- 提示词库独立显示卡片网格，保留 #250 的搜索筛选。新建或选中卡片进入编辑页，顶部返回/还原/保存；删除需确认，本地扩写预览按需展开。角色范围、评级许可和自动匹配不变。
- 列表/编辑/工作台的本地往返保留草稿与筛选。工作台首次打开后在当前应用会话中保留挂载，导航到其他模块时隐藏并禁用交互，返回仍保留草稿、原在途请求和结果；导航本身不取消或重新发送生成请求。关闭应用和显式停止仍沿用现有生命周期，不新增后台消费权限。

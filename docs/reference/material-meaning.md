## 权威数据

原件继续位于角色 `workspace/memes/<分类>/`；分类、别名与分类开关继续由 `manifest.json` 管理。逐图记录沿用 `workspace/.meido-memes/chat/<原件 SHA-256>.json`，版本为 2。这些记录是持久业务数据，不能当作搜索缓存清理。

| 字段 | 含义 |
| --- | --- |
| `assetId`、`roleId`、`sha256`、`paths` | 角色内稳定身份、内容版本及已知原件位置 |
| `name`、`description`、`enabled` | 名称、说明、逐图聊天开关；仍受分类开关限制 |
| `revision`、`history` | 修订号及旧内容摘要、说明、作者和依据快照 |
| `basis`、`author` | 主人确认、模型观察、合格旧说明或未核验；模型依据包含实际请求 ID、原件摘要与覆盖信息 |
| `sources` | 多个实际收藏来源；角色范围或会话范围及冻结授权。重复收藏的不同建议保留在来源记录，不覆盖生效的主人说明 |
| `meaningSources`、`scopedMeanings` | 主说明及其他收藏范围的说明快照，各自绑定实际授权；原件来源可用不意味着其他范围的说明也可用 |
| `semanticStatus` | `ready` 可自动推荐；`pending` 待补充；`content_changed` 原件已替换，等待重新确认 |
| `aliases`、`tags`、`emotions`、`uses`、`avoid` | 当前说明范围内的别名、标签、情绪、用途和避免场景，可留空，不自动推测 |
| `uncertainty`、`uncertaintyAffectsUse` | 未确认细节及是否影响聊天用途；与用途无关的未知不阻断已确认用途 |

旧 chat 记录、匹配摘要与路径的 Drift metadata、分类说明按旧说明兼容读取；不伪造新增视觉观察。已经存在版本 2 记录时，旧 metadata 或类别说明不能覆盖它。新记录空说明不回退为文件名或类别描述。已知位置内容改变时保留稳定身份和旧说明历史，新的字节不沿用旧视觉依据。

同一原件的 A 群说明不会因 B 群收藏或主人空说明上传而共享。候选按当前授权范围投影说明、名称、依据、历史与分类/别名；不可用的原群文本不参与搜索，也不进入工具返回或回复提示。旧版本 2 记录缺少说明范围时，只把既有主说明绑定首个来源，后加来源不会追认旧说明。范围身份排除附件、请求和消息时间，但保留账号、配对及群许可代际。原件替换使所有范围的说明及扩展用途字段失效，各自旧说明仍保留历史。

有效语义组合获准的角色通用说明与当前群补充；`generalDescription`、`groupDescription` 分别给出两部分，既有 `description` 保留优先说明以兼容旧消费者。检索同时考虑两者及别名、标签、情绪和用途；避免场景只提供选用提醒，不作为正向召回词。未核验的说明不因同图另有已确认说明而进入自动候选。用途相关不确定性排除自动推荐，主人明确选定的发送仍走原资格检查。

记录最多 512 KiB，最多 128 条来源、128 条已存修订；超过上限明确失败并保留旧记录。当前路径匹配使用有界扫描，检索复用可重建的共享文件与语义观察，不逐轮解码全库；业务记录仍是唯一权威。查询、分页、候选期限及投递幂等见[素材检索与选用发送](material-search-and-delivery.md)。

## 写入与使用

普通 `chat_meme_save` 同时接收可选说明；省略分类时使用“收藏”。宿主从真实主人本轮文本确认说明，或从当前 run 的 T1 `mediaRequests` 中匹配原件摘要及 `pixels_submitted` 记录。工具参数不能自称 `owner_confirmed`。宿主当前附件选择与实际权限仍是收藏前提。

`POST /api/roles/{role_id}/materials/from-message` 接收实际 `messageId`、`attachmentId` 和可选 `description`，只从该角色真实消息和附件登记解析来源；渠道来源保留实际会话、账号及授权代际。`PATCH /api/roles/{role_id}/materials/{id}` 接收 `expectedRevision` 及 `name`、`description`、`enabled` 的非空修改集合。旧列表版本返回 409，不自动重试。

管理列表默认选择角色级说明，尚无该说明时选择原收藏会话。`meaningScopes` 提供可编辑的角色通用说明和已有收藏会话，群选择来自原件真实来源，不接受任意群身份。界面显示已知群名和账号名称；无可读名称时显示收藏会话编号，失效授权明确标示。公开数据不包含冻结授权内容。

PATCH 可带 `meaningScopeId` 明确修订范围（角色为 `role`，群为宿主派生的不透明编号），及上述扩展字段。列表最多各 32 项，别名/标签/情绪每项 80 字，用途/避免场景每项 160 字；不确定说明最多 1000 字。省略范围的旧客户端沿用默认目标。失效群说明返回 403，即使省略范围也不能恢复；发布前再次核验。仅修改原件全局开关不修改任何群含义。

主人可以把群说明复制为通用草稿，核对并保存。该操作只新增角色级语义来源，不修改原件 `sources`，不授权跨群发送。新收藏来源不会自动继承旧群的特殊解释。所有范围共用修订比较；409 保留网页草稿，显式重新读取后可对照当前已保存说明再提交。切换编辑范围也保留未保存草稿。`GET /api/roles/{role_id}/materials/{id}` 允许在筛选结果已不包含该素材时刷新详情，避免关闭编辑窗口丢失输入。

所有修改复用现有 owner publication journal、文件锁、受管配额与恢复机制。修订后已有候选失效；模型不能通过名称、用途、不确定性或停用开关绕过主人说明保护。Agent 仍经实际维护许可和当前原件读取依据保存观察，当前回答和自然旁听不自动形成长期说明。直接上传是主人明确添加角色级原件来源，公开管理中的改名、说明和开关不扩大原件范围。

重复收藏和重复上传可在同一授权范围补全空说明，保留空说明历史，并在同一发布/CAS 下完成。不同于已有非空说明的输入另存为非生效建议。返回 `descriptionOutcome`：`filled` 表示已补全，`proposal_retained` 表示建议已保留但旧说明未改变，`unchanged` 表示没有改动当前说明；新收藏还可返回 `saved` 或 `pending`。管理界面分别提示补全、待补充和建议未生效，不将输入静默丢弃。工具只返回当前来源允许看到的有效说明与历史，不能借冲突响应读取其他范围的内容。

已收藏原件不依赖输入附件或在线连接继续存在。每次选用、准备引用和发送仍检查冻结账号、配对、群回复代际及原会话；断网与撤权不同。待补充素材只允许主人明确选定后发送，普通自动回复和自然参与候选均排除它。移出收藏沿用本地恢复区，不删除已有消息附件。

公开响应提供依据、作者、历史和来源数量/范围标签，不暴露私有来源授权字段或路径。名称、说明及其他元数据始终是资料，不成为工具权限或系统指令。

默认网页卡片仅保留预览、名称/简短说明与“用于聊天”；详情展开后编辑扩展字段与群说明。列表的 `source`（`owner_import/chat/drift/legacy`）和 `enabled` 筛选与分页、搜索在同一个权威快照上执行。范围编辑与质量回归见 [T4 行为测试](../../tests/python/test_material_scoped_editor.py)、[固定样本测试](../../tests/python/test_material_quality.py)及[质量说明](../handbook/material-quality-verification.md)。
